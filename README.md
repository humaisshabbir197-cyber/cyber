# Cyber Motion Portfolio

Production-ready React + Vite portfolio website featuring premium Framer Motion animations, Tailwind CSS styling, and React Router page transitions.

## Stack
- React + Vite
- Tailwind CSS
- Framer Motion
- React Router

## How to run
1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Start development server**
   ```bash
   npm run dev
   ```
3. Open the local URL shown by Vite (usually `http://localhost:5173`).

## Production build
```bash
npm run build
npm run preview
```

## Notes
- If your environment blocks access to `registry.npmjs.org`, `npm install` will fail regardless of app code.
- In a normal npm-enabled environment, the project should install and run directly with the commands above.
