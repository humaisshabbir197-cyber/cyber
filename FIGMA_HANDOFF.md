# NovaGlass UI — Figma Build Blueprint

This package mirrors a full multi-page Figma structure for a premium glassmorphism portfolio:

## Pages / Frames
- `Desktop / Home`
- `Desktop / About`
- `Desktop / Projects`
- `Desktop / Contact`
- `Mobile / Home`
- `Mobile / About`
- `Mobile / Projects`
- `Mobile / Contact`

## Reusable Components
- `Component / Glass Navbar`
- `Component / Glass Card`
- `Component / Glass Button`
- `Component / Glass Input`
- `Component / Section Container`

## Token Guidance
- Glass surface: `rgba(255,255,255,0.12)`
- Glass border: `1px rgba(255,255,255,0.20)`
- Background blur: `28px`
- 8px spacing system: `8 / 16 / 24 / 32 / 40`

## Motion-ready Layer Naming
- `ANIM__hero_headline`
- `ANIM__hero_copy`
- `ANIM__cta_group`
- `ANIM__cards_stagger`
- `ANIM__page_enter_left`
- `ANIM__page_exit_right`

## Interaction Intent
- Buttons: hover scale + glow
- Cards: hover tilt + media zoom
- Sections: fade-up and stagger reveals
- Page transitions: left/right slide
